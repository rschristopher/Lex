# Packs

**Rendered** Lex rows the engine loads. Not a scratch folder.

1. **Adapter** (`adapter.json`) — rare. Labels and formulas as data. Directory name is the adapter id.
2. **Classes** — slow. Reuse unless mechanics differ.
3. **Lore** — usual. Fold does not read it.

`universal/` is the native pack. `u-simplified/` is a second adapter on the same characters. Both are tracked. Any other pack is `data/packs/<id>/` and needs an explicit git exception to be public.

Raw books and publisher mapping notes belong in `data/ingest/`, not here.
