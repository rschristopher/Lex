# Cosmic tier examples

Draft GM examples of beings on each [cosmic tier](universal-system.md#cosmic-tiers), from traditional mythology, demonology, and early cosmic-horror fiction. A GM can place any being anywhere.

| Tier | Prefix | Gods and mythic beings | Demons | Cosmic horrors |
|---|---|---|---|---|
| Angels | mega | Pan, the Muses, Bastet | Andras, Furfur | the Deep Ones |
| Archangels | giga | Hermes, Heimdall, Anubis | Marchosias, Sitri | Dagon |
| Principalities | tera | Athena, Freyja, Thoth | Astaroth, Gremory | the Mi-Go |
| Powers | peta | Ares, Tyr, Sekhmet, Ishtar | Paimon, Asmoday | Cthulhu |
| Virtues | exa | Poseidon, Indra, Set | Bael, Belial | Shub-Niggurath |
| Dominions | zetta | Zeus, Odin, Ra, Marduk | Beelzebub | Nyarlathotep |
| Thrones | yotta | Kronos, Anu, Ymir | Leviathan | |
| Cherubim | ronna | Ouranos, Tiamat, Vishnu, Shiva | | Yog-Sothoth |
| Seraphim | quetta | Chaos, Brahma, Nu | Lucifer | Azathoth |

The demons are in the matching fallen tier, such as Lucifer among the Fallen Seraphim.
